# AI Mystery Room – Project Specification

## 1. Project Overview

AI Mystery Room is an AI-powered detective investigation web application. Players solve mysteries generated by Google's Gemini AI by investigating suspects, discovering clues, requesting hints, and identifying the culprit.

## 2. Problem Statement

Traditional puzzle games provide fixed stories and limited replayability. AI Mystery Room generates different mystery scenarios dynamically and provides an interactive investigation experience.

## 3. Target Users

- Students
- Puzzle and mystery enthusiasts
- Casual gamers
- People interested in AI-powered games

## 6. Difficulty Rules

| Difficulty | Suspects | Clues | Hints | Base Score |
|---|---:|---:|---:|---:|
| Easy | 3 | 5 | 2 | 100 |
| Medium | 4 | 7 | 3 | 150 |
| Hard | 5 | 9 | 3 | 200 |

## 7. User Flow

1. Open the website.
2. Click Start Investigation.
3. Enter a mystery premise.
4. Select difficulty.
5. Generate mystery using Gemini.
6. Read the case story.
7. Investigate suspects.
8. Discover clues.
9. Request hints if required.
10. Select a suspect.
11. Submit accusation.
12. Backend checks the culprit.
13. Backend calculates score.
14. Display final verdict and explanation.
15. Start another mystery.

## 9. API Endpoints

POST /api/cases
Generate a new mystery.

GET /api/cases/:id
Retrieve an active mystery without its solution.

POST /api/cases/:id/clues/:clueId/discover
Discover a clue.

POST /api/cases/:id/hints
Request the next available hint.

POST /api/cases/:id/accuse
Submit a suspect accusation.

GET /api/cases/:id/result
Retrieve the final result after the accusation.

GET /api/health
Check backend availability.

## 10. Scoring Rules

Correct accusation:
- Easy: 100 base points.
- Medium: 150 base points.
- Hard: 200 base points.

Additional rules:
- Each discovered clue: +5 points.
- Each hint used: -10 points.
- Minimum score: 0.
- Incorrect accusation: 0 points.
- Only one accusation per completed case.

Formula:

Final Score = Base Score + (Discovered Clues × 5) - (Hints Used × 10)

Scoring must be performed by the backend, never trusted from the frontend.

## 11. AI Generation Requirements

Gemini must generate:
- Mystery title
- Story
- Suspects
- Character descriptions
- Clues
- Hints
- Culprit
- Evidence-based explanation

The AI-generated mystery must have one identifiable culprit and a logically consistent solution supported by the clues.

Validate the response using Zod before storing it in MongoDB. Retry or return a safe error if generation fails validation.

## 12. Security Requirements

- Store Gemini API key in backend environment variables.
- Never expose the solution in public API responses.
- Never expose API keys in React.
- Validate all API inputs.
- Validate suspect and clue IDs on the backend.
- Prevent repeated accusations.
- Prevent hints beyond the difficulty limit.
- Calculate scores only on the backend.
- Do not commit .env files to GitHub.
